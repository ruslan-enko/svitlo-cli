# Svitlo CLI
Terminal app for monitoring power outage schedules in Lviv.

## Install

```bash
cd svitlo-cli
pip install -e .
```

## Run

```bash
svitlo-cli
```

## Controls

- `t` - Switch between today/tomorrow
- `r` - Refresh data
- `q` - Exit

## Features

- Timeline with light status
- Timer to next change
- Support for all groups (1.1-6.2)
- Next day schedule (when available)
